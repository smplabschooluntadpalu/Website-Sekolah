Website SMP Labschool UNTAD

SMP Labschool UNTAD Palu · Yayasan Bungamputi — versi custom bergaya Eduma, ringan, responsif, tanpa WordPress.

Halaman yang siap dibuka

Beranda gedung, kepsek, seragam Profil Sekolah visi, kepsek, struktur Program & Seragam seragam, ekskul, prestasi Berita filter kategori Galeri lightbox PPDB formulir + FAQ Kontak peta + form README panduan lengkap

Cara mengedit

  1. Ubah header/footer/menu di _src/header.html & _src/footer.html.
  2. Ubah isi halaman di _src/pages/*.html.
  3. Jalankan python3 _src/build.py untuk regenerasi semua halaman.
  4. Ganti foto di folder assets/ dengan nama file yang sama.
  5. Atur warna brand di css/style.css bagian :root.

Cara publish

  1. Buka app.netlify.com/drop atau Cloudflare Pages.
  2. Drag folder sekolah ke halaman tersebut — langsung online.
  3. Hubungkan domain nama-sekolah.sch.id lewat menu Domain.
  4. Formulir PPDB: sambungkan ke Google Forms / Formspree / WhatsApp (lihat README).
